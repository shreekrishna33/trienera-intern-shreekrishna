# Agriculture AI Tools Research and Analysis

## Project Overview

As part of my Week 1 internship task at TriEnera, I explored AI-powered tools and digital applications that support agriculture in India.

The goal of this project is to understand how technology is helping farmers with everyday challenges such as identifying crop diseases, accessing agricultural information, estimating crop yields, and making weather-based farming decisions.

I researched 10 agricultural tools and organized the information into a structured CSV dataset. I then used Python and pandas in a Jupyter Notebook to analyze the collected information and identify useful patterns.

This project gave me practical experience in researching AI applications, organizing data, and performing basic data analysis using Python.

## Objectives

* Research 10 agricultural tools relevant to Indian farming.
* Understand the purpose and functionality of each tool.
* Record the AI technologies, language support, strengths, weaknesses, and source links where available.
* Organize the collected information in a CSV file.
* Use Python and pandas to analyze the dataset.
* Identify patterns in the categories of agricultural tools.
* Document the findings and make the project easy to understand and reproduce.

## Tools Researched

The dataset includes the following 10 tools:

1. Plantix
2. Kisan e-Mitra
3. FasalNetra
4. ISAT (Intelligent Agricultural Systems Advisory Tool)
5. YES-TECH
6. CROPIC
7. National Pest Surveillance System (NPSS)
8. AgroBot
9. Meghdoot
10. Bharat-VISTAAR

These tools cover different areas of agriculture, including plant disease detection, pest surveillance, crop monitoring, weather-based advisories, crop yield estimation, and agricultural information services.

The research records include each tool's category, function, AI or technology used, language support, strengths, weaknesses, and source URL.

**Note:** Some technical details and language-support information still require verification. These entries should be confirmed using reliable sources before the research is considered final.

## How to Run the Project

Follow these steps to run the analysis on your computer.

### 1. Install Python

Install Python if it is not already available on your computer.

### 2. Install the required library

Open the VS Code terminal and run:

```bash
python -m pip install pandas notebook ipykernel
```

### 3. Open the project folder

Open the `trienera-intern-shreekrishna` folder in Visual Studio Code.

Make sure the CSV file and Jupyter Notebook are inside the same folder.

### 4. Open the notebook

Open `agri_ai_analysis.ipynb`.

Select your Python environment and run the notebook cells from top to bottom.

### 5. Review the output

The notebook performs the following tasks:

* Counts the total number of researched tools.
* Displays the names of the tools.
* Counts the tools in each category.
* Checks which tools mention Kannada language support.
* Checks for empty cells in the dataset.
* Identifies entries that may require further research.
* Displays a summary of the dataset.
* Saves a copy of the dataset as `agri_ai_tools_analyzed.csv`.

The analysis uses pandas to read the CSV file and work with its tabular data.

## Key Findings

The initial analysis produced the following findings:

### 1. The research covers 10 agricultural tools

The dataset contains 10 tools that support different agricultural activities. This provides an initial overview of the types of digital services available to farmers.

### 2. Plant disease detection is one of the categories represented more than once

The initial category analysis shows that **Plant Disease Detection** appears twice. The dataset also includes separate categories for pest surveillance, crop yield estimation, crop monitoring, weather-based advice, and agricultural assistance.

This suggests that the researched tools address several different farming needs rather than focusing on a single activity.

### 3. Language support and technical details need careful verification

Language accessibility is an important part of agricultural technology because farmers may prefer to receive information in their local language.

The analysis checks which records mention Kannada support and identifies entries containing words such as "verify" or "research." These checks help highlight information that should be confirmed before drawing firm conclusions about the tools.

**Research note:** These findings describe the current dataset. They should be updated if the research records change.

## Limitations

* The dataset contains only 10 tools and is not a complete list of agricultural applications available in India.
* Some AI technologies and supported languages still require confirmation from official sources.
* The analysis describes the information collected; it does not independently test each tool's accuracy or performance.
* The number of tools in a category does not indicate how effective or widely used those tools are.
* The project does not train a machine learning model or evaluate agricultural predictions.
